# Java GUI App (Swing)

> **Status: Archived** – Learning samples from 2023.

Simple Java desktop GUI applications using Swing.

## Requirements

- Java 11 or higher

## Project Structure

```
java-gui-app/
├── sample-1/          # Very basic window + button
│   └── Main.java
└── sample-2/          # Window with menu bar, about dialog, and layout
    └── Main.java
```

## How to Run

### Sample 1 – Basic Window

```bash
cd sample-1
javac Main.java
java Main
```

### Sample 2 – Menu + About Dialog

```bash
cd sample-2
javac Main.java
java Main
```

## What each sample shows

| Sample   | Features                                      |
|----------|-----------------------------------------------|
| sample-1 | JFrame + JButton                              |
| sample-2 | JMenuBar, Exit action, About dialog, layout   |
